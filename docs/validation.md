# Проверка 0.1.0

Дата: 10 октября 2026. Python 3.12.14, aiohttp 3.11.11, пакет Home Assistant 2024.12.5 с зависимостями, необходимыми для этих тестов.

Команда: `python -m unittest discover -s tests -v`.
Результат: **23 теста прошли, 0 ошибок, 0 пропусков**.

Проверено:
- увеличение бюджета текущих запросов 20 → 40 → 60 после HTTP 504 и возврат к 20 в следующем цикле;
- сообщение локального таймаута с лимитом последней попытки (40 секунд); тестовая транспортная обёртка ускоряет фактическое ожидание, запросы идут на реальный локальный HTTP-сервер;
- отключение повторов (0), применение двух повторов и реальной задержки между запросами;
- форма настроек HA: значения по умолчанию, сохранение выбранных значений и границы 0–5 / 1–60;
- восстановление после HTTP 503 и разрыва TCP; ограничение повтора при постоянном 503; отсутствие дополнительных повторов для некорректного JSON и отказа авторизации;
- сохранение безопасной причины ошибки в UpdateFailed и unavailable после неудачного опроса;
- декодирование очищенного реального ответа Solid X: мощность 1,5 кВт, теплоноситель 26 °C, помещение 21,7 °C, давление истории 1,101 бар;
- ошибки датчиков, локализованные числа, сортировка истории и порог устаревания;
- HTTP-клиент на локальном тестовом сервере: форма входа, Authorization, повторная авторизация после 401, отказ при повторном 401, ошибки JSON/Result, запрет редиректа и HTTP без согласия;
- реальные классы HA: сенсоры, уникальные ID, недоступность устаревших исторических значений;
- независимость исправного котла от ошибки другого котла и от недоступной истории;
- схема выбора котлов и создание данных config entry;
- синтаксис Python и корректность всех JSON.

Не проверено: полный запуск установленного HA с этой интеграцией, живой вход от вашего аккаунта из HA, установка из GitHub через HACS, совместимость со всеми новыми версиями HA. Тестовое окружение не является полной установкой HA со всеми встроенными интеграциями. Проверка реального API основана на предоставленном вами диагностическом JSON; ваш пароль и токен при разработке не использовались.

Архив содержит очищенную выборку показаний, без учётных данных и идентификаторов вашего котла.

При прогоне есть предупреждения об устаревающих API зависимостей старого HA (acme/pyOpenSSL/aiohttp). Тест отказа опроса намеренно вызывает одну запись уровня error. Ошибок тестов нет.

Публичный релиз 0.1.0 основан на rc4. Для HACS добавлены реальный codeowner, адрес README и issue_tracker.

Перед публикацией GitHub повторно выполнены 18 тестов API (все прошли). Окружение с пакетом HA из предыдущего прогона сейчас недоступно, поэтому пять тестов HA повторно не выполнялись. В коде поведения относительно проверенного rc4 изменений нет. GitHub Actions отдельно запускает тесты API и проверку HACS; brands исключён, поскольку это пользовательский репозиторий без регистрации бренда в Home Assistant.
